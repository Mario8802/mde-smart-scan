# Contributing

Contributions that improve extraction quality, accessibility, privacy or test coverage are welcome.

1. Create a focused branch.
2. Never add real customer, employee, address or shipment data.
3. Install `requirements-dev.txt` and run `pytest`.
4. Explain the user impact and security considerations in the pull request.
5. Keep integration adapters mocked unless an authorized public contract exists.

Synthetic fixtures should be clearly recognizable as fictional.
